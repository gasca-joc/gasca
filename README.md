# Banii pe bune – Chestionar (versiunea 2)

Site static (un singur fișier) pentru proiectul liceului despre banii adolescenților.

## Publicare pe GitHub Pages

1. Creează un repository public, de ex. `banii-pe-bune-2`.
2. Încarcă `index.html`, `README.md` și `.nojekyll` direct în rădăcină (Add file → Upload files, trage fișierele, nu folderul).
3. **Settings → Pages**: Source = *Deploy from a branch*, Branch = `main`, `/ (root)`.
4. Site-ul apare la `https://NUME.github.io/banii-pe-bune-2`.

## Fișiere

- `index.html`: site-ul, identic cu `Site_final_banometrie2.html`
- `.nojekyll`: publică fișierele exact cum sunt
